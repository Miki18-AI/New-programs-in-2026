# New-programs-in-2026
My little programs that I wrote for fun and they may have potential applications, but in my case they are just implemented for fun.


## 🚀 Инструкции по запуску и использованию

### 1. Веб-проекты (Анимации и Шифратор)
**Файлы:** `.html`, `.css`, `.js`
Эти проекты работают полностью в браузере, не требуют установки дополнительных серверов и подключения к интернету (все вычисления, включая криптографию, происходят локально, без использования ИИ-API).

* **Как запустить:**
  1. Скачайте нужный `.html` файл (например, `I_LOVE_YOU.html` или файл шифратора).
  2. Кликните по нему два раза, чтобы открыть в любом современном браузере (Chrome, Edge, Safari, Firefox).
* **Как пользоваться шифратором:** После открытия страницы используйте навигацию по вкладкам для выбора нужного алгоритма (Шифр Цезаря, ASCII и др.). Введите текст в левое поле, и результат мгновенно появится на экране.

### 2. Скрипты автоматизации (AutoHotkey)
**Файлы:** `.ahk`
Скрипты предназначены для работы в операционной системе Windows.

* **Как запустить:**
  1. Убедитесь, что на вашем ПК установлена программа [AutoHotkey](https://www.autohotkey.com/).
  2. Дважды кликните по скачанному `.ahk` файлу. В системном трее (в правом нижнем углу экрана) появится зеленая иконка с буквой "H".
* **Как пользоваться (на примере Автокликера):** Скрипт настроен на выдачу ровно 12 кликов в секунду. Для активации или деактивации кликера нажмите горячую клавишу, указанную в комментариях внутри самого кода (обычно это `F8` или `F9`). Чтобы полностью закрыть скрипт, нажмите правой кнопкой мыши по иконке "H" в трее и выберите "Exit".

### 3. Вычислительные программы (C++)
**Файлы:** `.cpp`
Код написан с акцентом на визуальную чистоту: для упрощения структуры в исходниках намеренно не используется префикс стандартного пространства имен (`std::`).

* **Как запустить:**
  1. Вам понадобится компилятор C++ (например, GCC/MinGW для Windows или встроенный компилятор в Linux/macOS).
  2. Откройте терминал в папке с файлом и скомпилируйте его командой: 
     `g++ filename.cpp -o program`
  3. Запустите готовую программу командой:
     `./program` (или `program.exe` на Windows).
* **Как пользоваться:** Следуйте инструкциям на экране. Программы для решения квадратных уравнений и химических расчетов попросят ввести исходные данные в консоль, после чего сразу выдадут результат.

### 4. Вычислительные скрипты (Python)
**Файлы:** `.py`
Скрипты написаны с использованием только простых арифметических действий, без перегрузки сложными библиотеками.

* **Как запустить:**
  1. Убедитесь, что установлен [Python](https://www.python.org/).
  2. Откройте терминал и выполните команду:
     `python filename.py`
* **Особые скрипты (Кастомные алгоритмы):**
  В репозитории присутствует специальный скрипт для расчета массивов данных, который использует строго заданный набор коэффициентов (1448, 67, 69, 52, 42, 228) и базовую арифметику. При запуске он автоматически просчитывает и выводит результаты в консоль без дополнительных вводов.
